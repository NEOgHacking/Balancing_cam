# Balancing_cam
This is a side project to improve on the ![balancing robot](https://gitlab.com/kloppertje/balancingrobot) with a new smaller esd protected pcb to prevent failures on the board, also to make the board smaller and make room for a second battery pack.
# PCB
<img width="1104" height="1082" alt="image" src="https://github.com/user-attachments/assets/2fa54adf-f165-4e28-a2ee-744df8c5703c" />
This is a small 50x50 PCB made in kicad, it uses the esp32s3 and tmc2209 stepper drivers.
# Specs
Using:
ESP32S3 mini 1
2x TMC2209 stepper drivers
LSM6DS3 IMU
2x battery pack of 2x 18650 cells so in total 4x 18650 cells
connectivity for rc reciever and VTX
